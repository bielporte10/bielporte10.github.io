Personal project

Gmail Agent Vault

A personal assistant that helps me read, search and organise my own Gmail inbox from my own computer.

What it is

Gmail Agent Vault is a small tool I built for myself. It connects an AI coding assistant running on my own machine to my own Gmail account, so I can ask it to summarise my inbox, find a specific message, label things, or draft a reply.

It is not a product, it is not for sale, and it has exactly one user: me.

How it works

  • It runs locally on my personal computer. There is no server and no website that processes mail.
  • It authenticates with Google using OAuth. I grant it access to my own account and nobody else's.
  • It reads messages only when I ask it to, and it never sends an email without me approving it first.
