Gmail Agent Vault

Privacy Policy

Last updated: 25 September 2026

Summary

Gmail Agent Vault is a personal tool used by a single person — its developer, Biel Porté — to access his own Gmail account. It runs locally on his own computer. It has no other users, collects no data from anyone else, and transmits nothing to any server operated by the developer.

Who operates this application

Gmail Agent Vault is operated by Biel Porté, an individual based in Catalonia, Spain. It is a personal project, not a commercial service, and it is not offered to the public.

What data the application accesses

When the developer authorises the application with his own Google Account, it may access, through the Gmail API:

  • The content, subjects, senders, recipients and dates of messages in that account
  • Labels and the ability to apply or remove them
  • Drafts, and the ability to create or modify them
  • The ability to send messages, only when explicitly instructed to do so

The application accesses only the account that authorised it. It cannot and does not access anyone else's mailbox.

How the data is used

Data is used solely to carry out tasks the developer asks for on his own mailbox: summarising recent messages, searching for a specific email, organising and labelling the inbox, and preparing draft replies.

Data is not used for advertising, profiling, analytics, training machine learning models, or any purpose unrelated to these tasks.

Storage and retention

The application runs entirely on the developer's own computer. It does not operate a server and does not maintain a database of message content.

The only credential stored is the OAuth token issued by Google, kept locally on that computer so the application does not need to re-authenticate on every use. That token can be revoked at any time from the Google Account permissions page, which immediately ends all access.

Sharing with third parties

Message content is not sold, rented, published, or shared with third parties.

The application works by passing content the developer selects to an AI assistant so it can be read, summarised or drafted against. That processing happens under the terms of the AI provider, and it occurs only for content the developer explicitly puts in front of it during a session. No bulk export or background synchronisation takes place.

Limited Use disclosure

Gmail Agent Vault's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions by removing "Gmail Agent Vault". Once revoked, the application can no longer read or send anything.

Children

This application is not directed at children and is not made available to any user other than its developer.

Changes to this policy

If the way the application handles data changes, this page will be updated and the date at the top revised.
